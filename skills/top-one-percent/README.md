## Install

Install this skill for your user account:

```bash
npx @tamng0905/builder-essential-skills --skill top-one-percent
```

Install it into the current repository instead:

```bash
npx @tamng0905/builder-essential-skills --skill top-one-percent --project
```

Restart Claude Code or Codex, then use it to understand a topic deeply or build
a rigorous path toward exceptional capability.

## What It Does

Top One Percent now routes each request to the right learning mode. For a
conceptual question, it answers first with a layered, first-principles
explanation grounded in mechanisms, examples, trade-offs, counterarguments,
and genuinely different perspectives. It does not replace the requested answer
with a roadmap, diagnostic, or quiz.

For an explicit mastery goal, it builds an adaptive system: map the domain,
identify what exceptional practice looks like, teach the foundations, and use
deliberate practice, feedback, readiness gates, and capstones to produce
credible evidence of skill. Ongoing tutoring proceeds one meaningful unit at a
time and adapts to observed gaps.

It does not promise that a learner can be ranked in a literal top one percent.
Instead, it makes the goal operational: define the target performance and use
credible evidence to show growing capability.

Deep-explanation example:

```text
Use $top-one-percent to teach me why local-first software is special. Explain
how it works, what complexity it moves around, and the strongest argument
against it.
```

Mastery example:

```text
Use $top-one-percent to help me become exceptional at product analytics. I know
basic SQL, have five hours each week, and want to lead a real analysis project
in six months.
```

The skill returns a complete explanation for the first request and a domain
map, staged curriculum, practice loops, assessments, purposeful resources, and
a realistic capstone for the second.
