# Paper Opportunity Radar

<p align="center">
  <a href="SKILL.md"><img src="../../assets/skill-banners/paper-opportunity-radar.webp" alt="paper-opportunity-radar — forensic research and opportunity discovery skill" width="100%"></a>

Traverse a chosen research topic over time, audit important papers at claim
level, check corrections and independent support, and turn credible overlooked
findings into testable project or business opportunities.

## Install

Install this skill for your user account:

```bash
npx @tamng0905/builder-essential-skills --skill paper-opportunity-radar
```

Install it into the current repository instead:

```bash
npx @tamng0905/builder-essential-skills --skill paper-opportunity-radar --project
```

Restart Claude Code or Codex, then invoke it with a topic:

```text
$paper-opportunity-radar Run today's cumulative sweep of low-cost desalination
research and find credible, unimplemented opportunities.
```

The skill preserves a corpus, paper dossiers, search coverage, an opportunity
ledger, and dated detailed reports so each run advances the work instead of
starting over.

See the full workflow in [SKILL.md](SKILL.md).
