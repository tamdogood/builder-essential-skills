# Name Your Business

<p align="center">
  <a href="SKILL.md"><img src="../../assets/skill-banners/name-your-business.webp" alt="name-your-business — fast strategic naming with selective live validation" width="100%"></a>
</p>

Turn a business idea into a fast agency-grade creative shortlist, then validate
the serious finalists when the decision warrants it. The workflow adapts to
startups, AI products, developer tools, protocols, open-source projects, local
services, professional firms, nonprofits, consumer brands, studios,
marketplaces, hospitality concepts, and holding companies.

It combines positioning, source-inspired naming, product-family architecture,
disciplined generation, spoken and technical stress tests, and selective live
screening. Fast mode does not browse. Validation mode checks only three to five
serious names across the surfaces relevant to the business, with a strict
two-part domain gate.

## Modes

- **Fast naming:** immediate creative favorite and compact shortlist, with no
  current availability claims.
- **Source-inspired naming:** preserve the mechanism or spirit of an existing
  project without copying its identity or implying affiliation.
- **Validation:** current company, domain, package, repository, marketplace,
  language, and preliminary trademark checks where relevant.

## Install

Install this skill for your user account:

```bash
npx @tamng0905/builder-essential-skills --skill name-your-business
```

Install it into the current repository instead:

```bash
npx @tamng0905/builder-essential-skills --skill name-your-business --project
```

Restart Claude Code or Codex, then try:

```text
$name-your-business Give me names for an AI-native networking startup.
$name-your-business Create a company name inspired by sslip.io, but broad enough to expand beyond DNS.
$name-your-business Create a company name, product family, CLI name, and domain strategy from one root.
$name-your-business Name a premium bookkeeping service for independent creative studios. I want an exact .com and plan to launch in the US.
```

The skill labels unresearched ideas as creative-only and reserves a final launch
recommendation for validated work. A domain is “verified available at check
time” only after an authoritative RDAP no-record signal and a live registrar
explicitly offer that exact domain. Domain status can change at any time, and
preliminary screening is not legal trademark clearance.

See the complete workflow in [SKILL.md](SKILL.md), the creative system in
[references/naming-strategy.md](references/naming-strategy.md), and the evidence
standards in [references/clearance.md](references/clearance.md).
